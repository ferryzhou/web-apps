# AI Agents in Practice

Real stories of AI agents solving problems, shipping features and moving business numbers, from 14 founders and engineering leaders (Anthropic, OpenAI, Shopify, Vercel, Ramp, Klarna, Sierra, Linear, SaaStr, Every, Sendbird).

- `index.html` (Latest): every interview across all people, newest first, grouped by month, with what was new in each one.
- `archive.html` (All people): each person's latest view and headline stories, filterable by story type.
- `people/<slug>.html`: one person's full picture: latest view, consolidated learnings, a newest-first timeline of their 2026 interviews (what each one added, and which stories it told), agent stories with sources, and interview notes.

Static HTML with a shared `style.css`, no build step at deploy time. The pages are generated from per-person JSON research files kept outside this repo. Numbers are the guests' own claims unless a source says otherwise.
