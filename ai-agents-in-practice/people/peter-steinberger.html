Peter Steinberger

Peter Steinberger bootstrapped PSPDFKit to a nine-figure exit, retired, and got pulled back into building by AI agents. Starting from a one-hour WhatsApp-to-Claude-Code prototype, he built OpenClaw—the fastest-growing open-source software project on GitHub—shipped 6,600+ commits in January running parallel agents, and joined OpenAI in February 2026 while placing OpenClaw in an independent foundation.

Latest view (Jul 9, 2026): As of mid-2026 he runs five to six parallel Codex sessions (down from ten as models got faster), rejects hands-off 'dark factories' because product taste requires human iteration, and works at OpenAI on persistent personal agents while steering OpenClaw through an independent foundation modeled on Ghostty's.

Consolidated learnings

  • Every developer should implement a basic agent loop once—prompt, reason, tool call, observe, repeat. It is the 'Hello World of AI' and dissolves the illusion of magic.
  • Treat CLIs and one-sentence Skills as the default tool interface over MCP: CLIs are composable with Unix pipes and models already excel at calling them.
  • Practice empathy for an agent that wakes up with zero memory every session. Structure codebases so the agent can read the code to answer its own questions.
  • Watch out for the 'agentic trap' U-curve: start with simple prompts, overcomplicate with heavy multi-agent orchestration, then return to simple prompts and direct steering.
  • Reject fully predetermined 'dark factories' for real products. Good software is discovered by playing and iterating—'the agent runs the inner execution loop; I set direction and decide in the outer loop.'
  • Faster inference reduces how many parallel agent windows you need: he dropped from ~10 sessions to 5 or 6 once models sped up.
  • Taste starts with detecting 'AI smell' (generic UI borders, purple gradients, forced copy triads) and rises to hand-crafted personality details like soul.md.
  • Any useful personal agent sits inside the 'lethal trifecta' (private data + untrusted content + external communication)—treat permission design and sandboxing as existential, and expect an AI-generated flood of security advisories.

Agent stories

One-hour WhatsApp-to-CLI hack becomes GitHub's fastest-growing software repo

  • launched something
  • 6,600+ commits in January; 295K+ GitHub stars, ~2,000 contributors

Steinberger spent an hour wiring WhatsApp to Claude Code's CLI (-p). Three months and thousands of parallel-agent commits later, OpenClaw became the fastest-growing runnable open-source software project on GitHub and led to his move to OpenAI.

Details
  • Running 4 to 10 agents simultaneously, he logged over 6,600 commits in January 2026 alone.
  • By April-May 2026, OpenClaw had crossed ~2,000 contributors, ~30,000 PRs and hundreds of thousands of GitHub stars (with corporate contributors from NVIDIA, Microsoft, Red Hat, Tencent and ByteDance).
  • In February 2026 he joined OpenAI to build personal agents ('an agent even my mum can use') while moving OpenClaw to the independent OpenClaw Foundation.

OpenClaw autonomously figures out voice-note transcription in Marrakesh

  • solved a problem
  • Zero custom audio code; agent chained FFmpeg + curl + Whisper API on its own

While traveling in Marrakesh, Steinberger sent a WhatsApp voice message to his early OpenClaw prototype even though he had never added audio support. The agent solved it on the fly using standard Unix tools.

Details
  • The agent inspected the unknown attachment's file header, converted the audio with FFmpeg, located his OpenAI API key in the environment, and called the Whisper API with curl.
  • That single moment convinced him that giving a capable model Bash and CLI access beats pre-building rigid integrations.

Self-modifying agent debugs its own source and writes its own soul.md

  • built a feature
  • Agent edits its own harness and consolidates memory via 'dreaming'

OpenClaw knows its own repository and harness, allowing Steinberger to debug and extend the agent by talking to it—and inspiring both its self-authored soul.md personality file and its idle-time 'dreaming' memory consolidation.

Details
  • When WhatsApp replies felt too stiff, he had the agent draft a soul.md defining voice, pacing and opinions; it also gained a proactive cron heartbeat that checked on him after shoulder surgery.
  • In April 2026 he shipped an initial 'dreaming' pass that walks session logs during idle time to promote durable memories and discard noise.
  • He also candidly acknowledged a rough week in May 2026 (release 2026.4.29) and slimmed core down by moving optional features out.

OpenClaw absorbs 1,142 security advisories in five months—mostly AI slop

  • solved a problem
  • 16.6 advisories/day (2x Linux kernel); 469 fixes published, 60% closed

OpenClaw's viral growth turned it into a magnet for AI-driven vulnerability scanners: 1,142 security advisories arrived in 153 days—nearly double curl's 27-year lifetime total—forcing new triage heuristics and exposing real ecosystem risks.

Details
  • 99 advisories were marked critical; the team published fixes for 469 and closed 60%.
  • Steinberger's triage rule: the louder and more apologetic the report, the more likely it is AI-generated CVE-farming slop.
  • Independent scans also showed real exposure when users ignored defaults (publicly exposed instances and malicious third-party ClawHub skills), underscoring the 'lethal trifecta' warning he gave on stage.

VibeTunnel turns any browser into a Mac terminal controller in one day

  • built a feature
  • Built in 1 day with Claude Code to steer parallel agents on the go

Before OpenClaw, Steinberger built VibeTunnel in a single day using Claude Code, named pipes and xterm.js so he could monitor and command his army of local coding agents from any browser without SSH.

Details

Interview notes

Peter Steinberger: Shipping OpenClaw at Inference Speed

Peter Steinberger (PSPDFKit founder, OpenClaw creator, now at OpenAI) across The Pragmatic Engineer (Jan 2026), Lex Fridman #491 (Feb 2026), State of the Claw (Apr 2026) and AI Engineer World's Fair (Jul 2026).

How he builds

  • Shipped 6,600+ commits in January running 4 to 10 parallel agents; later settled on 5 to 6 windows as model latency dropped.
  • Prefers Codex for deep repo work (quieter, reads more code by default) and CLIs + Skills over MCP.
  • Still rejects hands-off 'dark factories': the agent owns the inner execution loop, while the human stays in the outer loop to taste, steer and reject features that smell like AI.

Hard lessons from hyper-growth

  • 1,142 security advisories in five months showed that AI vulnerability scanners have broken traditional open-source triage.
  • Moved OpenClaw into a Ghostty-modeled independent foundation so corporate contributors can invest without any single lab owning it.
