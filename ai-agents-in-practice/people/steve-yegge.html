Steve Yegge

Steve Yegge spent decades writing systems software at Geoworks, Amazon, Google, Grab, and Sourcegraph before co-authoring Vibe Coding and building Beads and Gas Town—open-source tools for running 20 to 30 coding agents in parallel. He popularized the eight stages of AI developer evolution and treats multi-agent orchestration like a chaotic industrial factory.

Latest view (Jul 6, 2026): As of mid-2026 he argues that brittle deterministic orchestration code should be stripped back in favor of letting models work inside durable issue-backed workflows, while bringing Gas Town to the cloud with Kilo and warning that running large agent fleets drains human energy like a vampire.

Consolidated learnings

  • Treat agent sessions as ephemeral 'cattle' and persist all work state, identities, and workflows in a durable Git-backed ledger (Beads) so any fresh session can pick up after a crash or compaction.
  • Match context strategy to task type: give well-specified subtasks to small-context ephemeral workers (Polecats) and keep long-lived, high-context Crew agents for open-ended design.
  • When running parallel agents at scale, merge conflicts become the bottleneck—you need a dedicated merge-queue role (Refinery) to serialize and reconcile changes intelligently.
  • Keep context windows as short as possible for routine work to avoid quadratic cost growth and cognition drop-off, and hand off sessions frequently.
  • Don't over-engineer deterministic orchestration pipelines: rigid step-by-step harness code becomes brittle; use durable workflow checklists ('molecules') and let capable models recover nondeterministically.
  • Use rapid prototyping for optionality—build multiple versions to defer big decisions until you can see which one works—and remember that ambition will always outstrip compute.
  • Beware the 'vampiric effect': supervising fleets of fast agents drains human energy far faster than manual coding, and token spend scales aggressively across multiple accounts.

Agent stories

Gas Town orchestrator built in 17 days to run 20 to 30 coding agents at once

  • launched something
  • 75K lines of Go, 2,000 commits in 17 days; 20-30 concurrent agents

After three failed 2025 orchestrator attempts, Yegge open-sourced Gas Town on January 1, 2026—a Go-based, tmux-driven multi-agent factory written in 17 days without him reading the code, built to run 20 to 30 Claude Code instances simultaneously.

Details
  • Assigns coding agents to seven roles: Mayor (chief of staff), ephemeral Polecats (workers), Refinery (merge queue), Witness (rig monitor), Deacon (patrol daemon), Dogs (maintenance helpers), and Crew (interactive design agents).
  • He explicitly warned anyone below Stage 6-7 of AI adoption—or anyone who cares about token cost—not to run it, noting he had to open multiple Claude Code accounts to feed it.
  • Proved long-horizon durability by running a 1,000-step 10-disc Towers of Hanoi workflow in minutes via molecular wisps.

Beads gives agents durable Git-backed memory—without Yegge reading the code

  • launched something
  • 225K lines of Go; tens of thousands of daily users (claimed)

Born from a 15-minute design compromise with Claude (Git JSONL plus SQLite) in October 2025, Beads became a widely used issue-graph memory layer for coding agents—and the control plane underneath Gas Town.

Details
  • Stores tasks, epics, agent identities, hooks and mail as queryable Git-tracked JSONL issues (bd create, bd ready).
  • Yegge says he never looked at Beads' 225,000 lines of Go code, relying on tests and usage instead.
  • Allows any successor agent session to inspect prior state after a crash or context compaction and continue seamlessly.

Molecular workflows carry agents across a 20-step release process without skipping steps

  • solved a problem
  • 20-step release chain survives crashes, CI waits and context compactions

Agents routinely dropped steps during Beads' 20-step release process because of long CI and GitHub Actions waits. Yegge encoded the process as a 'molecule'—a chained graph of Beads issues—so ephemeral agents walk it atomically to completion.

Details
  • When a workflow hits a Gate (such as waiting for CI/CD), the Polecat worker shuts down and Gas Town wakes a fresh worker once the gate clears.
  • Yegge calls this 'Nondeterministic Idempotence' (NDI): sessions crash and take different paths, but persistent Git state and acceptance criteria drive the workflow to finish.
  • He also encoded Jeffrey Emanuel's 'Rule of Five' (four structured review passes) as composable TOML Formulas.

Refinery merge queue and gt seance tame multi-agent rebases and handoffs

  • solved a problem
  • Dedicated Refinery agent serializes merges; workers revive predecessors via /resume

Swarming 20+ agents on one repo caused 'monkey knife fights' over Git rebases and lost context across session handoffs. Yegge added a dedicated Refinery merge-queue agent and gt seance, letting a new worker revive its dead predecessor to ask what it left behind.

Details
  • The Refinery merges one branch at a time to main and reimagines patches cleanly when main has drifted.
  • gt seance uses Claude Code's /resume command with tagged session IDs so a successor Mayor or worker can directly interrogate the previous session.
  • Paired with GUPP ('If there is work on your hook, YOU MUST RUN IT') and automated gt nudge tmux pokes to keep polite models from stalling.

Interview notes

Steve Yegge: Gas Town, Beads, and the 8 Stages of AI Coding

Steve Yegge (veteran of Amazon, Google, Grab and Sourcegraph; co-author of Vibe Coding) across his Jan 1 essay Welcome to Gas Town, Intelligent Machines (Feb 2026), The Pragmatic Engineer (Mar 2026), Live with Tim O'Reilly (Mar 2026) and AI Native Dev (Jul 2026).

How Gas Town works

  • Beads: Git-backed JSONL + SQLite issue graph storing tasks, agent identities, mail and hooks so ephemeral Claude Code sessions can crash and hand off without losing work.
  • Seven roles: Mayor, Polecats (small-context ephemeral workers), Refinery (merge queue), Witness, Deacon, Dogs and Crew (high-context interactive design agents).
  • MEOW stack: Chained Beads ('molecules'), templates ('protomolecules'), TOML Formulas and ephemeral patrol Wisps delivering 'Nondeterministic Idempotence.'

Honest warnings

  • Calls Gas Town chaotic, expensive ('cash guzzler' needing multiple Claude Code accounts), and only for Stage 6-7+ developers already juggling 5+ agents daily.
  • By July 2026, cautions against brittle deterministic orchestration glue—favoring durable state and letting capable models recover.

Code size, commit and adoption numbers (75K lines of Go and 2,000 commits in 17 days for Gas Town, 225K lines and tens of thousands of daily users for Beads, 20-30 concurrent agents) are Yegge's own accounts from his Medium essays and interviews and were not independently verified.
