# Battle Maps

A collection of interactive visualizations of historical military campaigns and battles.

**Live:** [https://ferryzhou.github.io/web-apps/battle-maps/](https://ferryzhou.github.io/web-apps/battle-maps/)

## About

This is a landing page that gathers the repo's battle and campaign maps in one place. Each entry links to a self-contained interactive map.

## Maps

- **桓温第三次北伐 · Huan Wen's Third Northern Expedition** — The 369 CE campaign against Former Yan, including the advance, the Huangong Canal, and the rout at the Battle of Fangtou.

## Adding a new map

1. Build the map as its own self-contained app folder at the repo root (e.g. `my-battle/index.html`).
2. Add a `.map-card` link to `index.html` here pointing at the new folder.
3. List it under **Maps** above.
