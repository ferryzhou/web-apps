# 中国历史地图 · 开发计划

配套设计见 [DESIGN.md](./DESIGN.md)。本计划分阶段推进，每阶段产出**可演示、可审阅**的结果，
符合本仓库"小步、可移动端 review"的节奏。

## 阶段总览

| 阶段 | 目标 | 产出 | 状态 |
|------|------|------|------|
| 0 | 构思与文档 | DESIGN / ROADMAP / 示例数据 | ✅ 进行中 |

## 阶段 1 · 数据层落地（战国）

把现有 `index.html` 里的硬编码数据，按新模型迁移为规范化 JSON。

- [ ] 抽取战国七雄 → `states.json`（含 existence、color、引用 id）
- [ ] 抽取都城/战场/关隘 → `places.json`
- [ ] 抽取君主/将领/谋士 → `people.json`（去重，跨政权独立）
- [ ] 抽取战役/变法/统一 → `events.json`
- [ ] 现有多边形坐标 → `data/territories/<state>/<year>.geojson`
- [ ] 写 `tools/validate.mjs`：校验 id 唯一、引用完整、时间合法
- [ ] （可选）GitHub Action：PR 时自动跑校验

**验收**：`node tools/validate.mjs` 通过；数据可被简单脚本读出并自洽。

## 阶段 2 · 地图渲染重构（Leaflet）

- [ ] 新建应用外壳 `index.html` + `css/style.css` + `js/` 模块骨架
- [ ] `data.js`：fetch 全部 JSON，建立 `byId` 索引与时间查询 API
- [ ] `map.js`：用 Leaflet 渲染**单一固定年份**的疆域多边形 + 地点标记
- [ ] 去掉 Google Maps 及硬编码 API key
- [ ] 选定开源底图（浅色瓦片）

**验收**：打开页面能看到某一固定年份（如 -260）的战国地图，数据全部来自 JSON。

## 阶段 3 · 时间轴 + 疆域变迁

- [ ] `timeline.js`：连续滑块 + 朝代刻度 + 自动播放
- [ ] 年份变化 → `map.js` 按 3.3 节快照规则重绘疆域
- [ ] 政权按 `existence` 出现/消失；事件标记按日期出现
- [ ] 平滑过渡/防抖，避免拖动时卡顿

**验收**：拖动时间轴，疆域随年份变化（至少 2~3 个战国疆域快照可见差异）。

## 阶段 4 · 实体详情 + 关联跳转

- [ ] `detail.js`：点击政权/地点/事件 → 详情面板
- [ ] 详情中列出**关联实体的可点击链接**，实现实体间跳转
- [ ] 人物视图：生卒、所属、参与事件
- [ ] 事件视图：时间、地点、涉及政权与人物

**验收**：从「秦」能点进白起 → 点进长平之战 → 点回赵国，链路闭环。

## 阶段 5 · 体验打磨 + 扩展到秦汉

- [ ] 可分享 URL（`?year=&focus=`）状态还原
- [ ] 移动端布局（详情面板底部抽屉、时间轴可触控）
- [ ] a11y：键盘操作时间轴、语义化、对比度
- [ ] 内容扩展：秦统一、楚汉之争、西汉疆域快照
- [ ] 更新根 `README.md` 应用条目

**验收**：移动端可用、可分享；时间轴覆盖战国→西汉的连续疆域变迁。

## 数据贡献流程（面向后续）

1. 在对应 `data/*.json` 增改实体，遵循 [DESIGN.md](./DESIGN.md) 第 3 节 schema。
2. 疆域多边形可用 [geojson.io](https://geojson.io) 手绘后存入 `data/territories/`。
3. 本地跑 `node tools/validate.mjs` 确认无引用断裂。
4. 提交 PR，保持改动聚焦、可移动端审阅。

## 待定/开放问题

- 底图选型：浅色现代瓦片 vs. 纯地形/无注记底图（避免现代国界干扰）。
- 疆域精度策略：先粗后精，存疑边界如何在 UI 上标注（虚线/低透明度？）。
- 是否需要"模式切换"：疆域模式 / 人物关系模式 / 事件时间线模式。
- MapLibre 迁移时机：何时从 Leaflet 切换以获得矢量平滑缩放。
