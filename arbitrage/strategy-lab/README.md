# Arbitrage Strategy Lab

A thinking tool for "profit from unequal prices" across any market: a taxonomy of
six price-gap domains graded by speed/capital/friction, a five-test screening
framework (same-claim, staleness, all-in cost, capacity, persistence), an edge
calculator that prices leg risk (EV per cycle, breakeven fill rate), and a
per-domain research-plan generator with Markdown export.

Open `index.html` — no build step, no network calls.
